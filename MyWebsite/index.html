About me

Hi, I’m Mohamed Ahmed Alnayed, a Computer Science student in Egypt and a hands-on software developer. I enjoy the full journey of a product: sketching the idea, designing the screens, writing the code and shipping something that works.

My main focus is mobile development with Flutter and Dart, backed by solid experience in ASP.NET Core MVC, SQL Server and Java Spring Boot. That mix lets me build an app, the API behind it and the database underneath it, end to end.

I learn best by building. Every project I take on pushes me to try a new tool, fix real bugs and deliver complete work, not half-finished demos. I like clean UI, readable code and projects that are fully finished, from the first screen to the final handoff.

I also enjoy leading. I’m the team leader of an 8-person group building Real Estate Maven, where I organize tasks, review progress and keep everyone moving toward the same goal. I believe good teamwork and clear communication are as important as good code.

Right now I’m working on my graduation project, a smart campus system that combines a 3D model, a mobile app, sensors, an ID gate and a robot. I’m always open to new projects, internships and collaborations.
